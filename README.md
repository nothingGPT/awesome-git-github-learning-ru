# 📚 Awesome Git & GitHub Learning RU

📚 Коллекция русскоязычных видео и курсов по Git и GitHub с практикой.

---

## 📜 О проекте

Подборка создана для начинающих программистов, изучающих Git и GitHub. Она включает русскоязычные видеоуроки и курсы — от базовых команд до продвинутых возможностей и практического применения. Цель проекта — помочь начинающим сэкономить время на поиске качественных образовательных материалов.


---
## 📚 Подборка материалов

В нашей коллекции собрано 16 русскоязычных видеоуроков и курсов по Git и GitHub, разделённых на три категории:

- 🌱 **Git & GitHub с нуля** — 7 материалов для начинающих.
- 🛠️ **GitHub на практике** — 5 материалов по GitHub Pages, Pull Requests, GitHub Actions и командной работе.
- ⚡ **Продвинутый Git** — 4 материала по сложным командам, работе с историей и разрешению конфликтов.
